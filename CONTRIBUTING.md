## Como executar localmente

Pré-requisito: [Docker](https://www.docker.com/) (com o plugin Docker Compose).

```bash
docker compose up
```

Acesse no navegador: `http://localhost:8000` (o MkDocs redireciona automaticamente para `/IHC_2026.2_Grupo05/`, prefixo definido em `site_url`). As alterações em `docs/` e `mkdocs.yml` são refletidas automaticamente. Para parar, pressione `Ctrl+C`.
