## Como executar localmente

1. Instale o tema Material para o MkDocs:
```bash
pip install mkdocs-material
```

2. Execute o servidor local de desenvolvimento:
```bash
mkdocs serve
```

3. Acesse no navegador:
`http://localhost:8000`
